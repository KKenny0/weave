# 把研究写成能独立阅读的解释

在需要组织跨材料解释、展开机制、处理读者前提或修订表达时读取。目标是第一次交付就有足够好的完整文章，质量由写作者承担，不依赖用户先审样章或事后补研究。

## 写作前的质量判断

回看原委托和后续修正，判断当前证据与解释是否足以完成它。分开文章必须回答的问题、必要背景和可以略过的延伸。篇幅和解释深度向用户关心的问题倾斜；重点难、材料难找，不构成把篇幅转移到容易写的背景的理由。

在工作记忆中确认文章怎样推进：从什么具体问题进入，以什么机制、对象、对比或关系贯穿，读者在哪一步获得新的判断能力。对各段落或章节至少能说清它回答什么、用哪些证据、前提是否已出现、为何需要例子或边界。无需另存提纲契约或内部字段。

落笔前应能用自己的话重建承重机制，并走通一个具体例子。若只能说“这个概念很重要”，无法解释部件如何作用、输入如何改变结果，先返回研究。若暂定 frame 无法容纳用户重点，调整 frame；若重点缺证据，说明限制，而非删除重点。

## 依照读者需要组织

用户的目标直接决定解释方式，不必先命名模式：

- 要讲懂时，按概念依赖推进，从具体困境到必要区分，再展开机制、例子和边界。术语在第一次承重处解释，不能把基础外包给文末阅读清单。
- 要认识格局时，用同一分类问题和抽象层级建立坐标；交叉维度作为不同轴呈现。说明混合方法如何放置、放置需要什么证据，以及地图不能判断什么。
- 要评估时，围绕会改变主张可信度的证据组织，分开测量、解释、替代原因和缺失比较。
- 要决策时，说明哪些条件改变选择，连接收益、代价、失效条件和可验证办法；代表性案例不等于普遍建议。
- 要入门时，按前提和待消除的不确定性安排顺序，解释下一步为何需要前一步，同时在正文完成已承诺的基本模型。

这些需要可以组合，但篇幅仍服从用户重点。不要把多种需要扩成并行文章，也不要让材料格式重新决定整篇工作流。

全系统解释先让读者知道工具是什么、谁使用、解决什么问题、核心状态和边界，再用一条代表任务连起机制。局部实现回接整体能力和代价。多个来源共同解释一个问题时按关系组织；“作者 A 的摘要、作者 B 的摘要”并排通常不能构成综合判断。

## 让机制和例子承重

背景铺到能够进入核心问题即可。每个关键抽象都应接通可观察的情境：谁或什么处于何种状态，发生什么变化，哪个部件使变化成立，为什么另一种结果没有出现。需要公式时解释变量、关系与适用条件；需要代码时说明它展示或验证什么，不用大段源码替代解释。

例子应完成推理：给出必要输入或初始条件，逐步展示机制如何作用，解释结果和失败条件。只把术语换成生活名词的类比无法证明机制；用类比时说明对应部分与不对应部分。事实案例要有来源，教学构造和假设推演要标清身份。

用户希望迁移判断时，使用机制处理一个有实质差异的情形，并明确哪些条件保持、哪些改变、哪里不再支持推广。若证据只支持原场景，保留这个限制，不为满足“有启发”而添加通用建议。技术迁移还需执行部件、配置与环境依赖，以及移除必要部件后的后果。

具体对象随章节发生变化时可以沿其变化推进；矛盾和反例承重时可按争论及其解决条件推进。无需固定章节数量、状态标记或统一叙事弧。开头和标题以最终实际展开的内容为准，正文稳定后重新校准承诺。

## 图形是解释的一种选择

任何材料都可以使用必要图形。研究中发现关系证据时就考虑它是否需要图；写作时先确保相关概念和情境可理解，再选择最容易恢复关系的表征。流程与所有权适合结构图，状态变化适合序列或轨迹，反馈适合回路，多个相同维度的比较适合小表格。公式或曲线只在核心关系需要时使用。

对每个保留图执行删除判断：去掉它是否使一个重要关系明显更难理解？若只是把邻近文字装进框里，删除。零张图完全有效，无需每章一图、强制 marker 或 Org 块。

图中每个节点、箭头、曲线、数量和比较尺度必须能回到证据，综合推断应明确标注。相关不画成因果，假设曲线不画成实测数据，示意比例不暗示真实效果量。图旁放必要说明、证据和适用条件，检查只看图与说明时会不会得出正文未获支持的结论。选择目标 Markdown 环境能显示的格式，核对渲染或可读性与资产链接；不能渲染时用可靠文字、表格或简化图，不声称已验证。

## 结构与表达修订

完整初稿写完后，从整体到局部修订。先检查用户重点是否得到足够深度，核心模型是否连贯，前提是否按需到场，章节是否重复或只贡献背景。删掉无法回答“这部分让读者多理解了什么”的内容；重要缺口返回研究，不用过渡句掩盖。

再检查段落和句子：主张后有具体机制或依据，例子之后说明它证明到哪里，来源立场与自己的解释保持可辨。删除没有新增意义的段末总结、空泛升华、机械并列、重复预告和过度强调；把虚泛形容改为具体事实，保持句长和节奏自然。对比、短段、破折号或加粗是否保留由语义和阅读需要决定，不实行绝对句式禁令。

用户明确提供的风格样本可以帮助确定措辞和节奏；只读取当前任务已在范围内的样本，不为模仿口吻扫描知识库、私聊或个人目录。样本是表达参考，不能覆盖证据边界、删掉反证或强迫不同主题套同一结构。

## 影响与公开读者

结论先完成研究问题的解释闭合。只有有来源的个人背景与研究发现确实改变具体判断时，才进一步写个人影响；纯理解需求可以停在条件化认识。没有新增影响就省去，不强制固定“意味着什么”标题、数量或零增量占位。

用户明确面向公众写作时，读者所处情境和前提可以改变搜索范围、证据选择和解释顺序。若只是措辞、开头或节奏问题，在写作中处理，不制造额外研究流程。传播目标不能降低来源标准、隐藏反证或放大结论；时效性文章可以明确只回答当前版本或事件，不强造常青意义。

文章就绪前由写作者完成目标、仅凭成稿的自足性、事实和实际文件审阅，见 [review.md](review.md)。用户可以继续提出修改，但这种选择不是初稿达到可交付质量的替代条件。
